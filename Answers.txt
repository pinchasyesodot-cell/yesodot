 מה ההבדל בין קוד אסינכרוני )Asynchronous )וקוד סינכרוני )Synchronous?)
a. תנו דוגמא לקוד אסינכרוני ב־NodeJS.
b. תנו דוגמא לקוד סינכרוני ב־NodeJS.

קוד סינכרוני זה קוד שעובד לפי סדר הפעולות שהקוד נכתב פעןלה ב' לא תקרה לפני שפעולה א נגמרה.
דוגמא:
console.log("a");
console.log("b");
console.log("c");

קוד אסינכרוני זה קוד שרץ ברקע והפעולה הבאה בקוד קורה במן הזה
דוגמא:

const data =  await setTimeout(() => {
  console.log("a");
}, 2000);

const data2 =  () => {
  console.log(data);
};
data2();
console.log("b");

הבדל 1:
js בדפדפן זה בצד הלקוח אחראי על ui ועדכון הDOM
NodeJS מאפשר להריץ. jS מחוץ לדפדפן בצד השרת.
הבדל 2:
js בדפדפן אין לא אפשרות לכתוב ולקרוא קבצים.
nodejs יש לו אפשרות לקרוא ולכתוב קבצים במחשב.
הבדל 3:
js בדפדפן הובייקט הגלובלי זה window
nodejs האובייקט הגלובלי זה global
